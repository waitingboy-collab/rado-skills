# Rado skills

Портфолио „Човек + AI“ на Радослав Чакъров.

Целият сайт е в един файл: `index.html` (HTML, CSS и JS са вътре). Няма библиотеки и няма build стъпка.

## Идеята
- **Синьо-сивият моноширинен текст** е гласът на AI (черновата).
- **Червеният ръкопис** е твоята корекция. Задраскванията се рисуват на ръка при скролване.
- Ключът **„Червен химикал“** горе скрива всички корекции. Така посетителят вижда разликата между „само AI“ и „AI + човек“.
- **Хартията за чертеж, чертежите и щампата най-долу** напомнят за CNC миналото ти. Във „Проверил“ е твоят подпис.

## Преди да публикуваш, провери текстовете
Петте корекции съм ги написал по кратки бележки за проектите ти. Прочети ги и поправи каквото не е точно, особено:
1. SEV&BRO: RLS бъгът при изтриване
2. Save Animals Plovdiv: pg_net тригерът

## Как се редактира
Всеки текст е два пъти, по веднъж за всеки език:
```html
<span lang="bg">Български текст</span><span lang="en">English text</span>
```
- **Нов проект:** копирай един `<li class="p" data-cat="...">` в `#index`. Категориите са `biz`, `com`, `qa` и `app`. Броячите на филтрите се обновяват сами.
- **Нова корекция:** копирай един `<article class="case">`.
- **Задраскан текст:** `<span class="del">…</span>` вътре в елемент с клас `strike-host`. Задраскването се рисува автоматично.
- **Маркер:** `<span class="hl">…</span>`.
- **Нещо само за химикала:** добави клас `pen`. Изчезва, когато химикалът е изключен.
- **Цветове:** блокът `:root` най-горе в `<style>`.

## Публикуване
- **GitHub Pages:** създай публично репо `rado-skills`, качи `index.html` и `README.md`, после Settings → Pages → Branch: `main`, папка `/ (root)`. Адресът ще е `https://waitingboy-collab.github.io/rado-skills/`.
- **Vercel:** импортирай репото `rado-skills` и deploy, без настройки. Адресът ще е `rado-skills.vercel.app`, ако името е свободно.

Езикът се избира по браузъра (за български е BG, иначе EN) и се запомня.
